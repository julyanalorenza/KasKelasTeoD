# KasKelasTeoD
KasKelasTeoD adalah aplikasi untuk memudahkan pengelolaan uang kas kelas. Siswa dapat mengisi pembayaran dan mengirim bukti transfer, sedangkan bendahara dapat memverifikasi pembayaran, mencatat pemasukan dan pengeluaran, serta memantau saldo kas. Aplikasi ini dibuat agar pencatatan kas lebih praktis, rapi, dan mudah dipantau.
